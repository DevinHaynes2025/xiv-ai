**AgentCivilizationLayerV100** — durable agent society plane under Guardian.

**Identity fields (minimum):**
- `agent_id` (stable logical id)
- `agent_class` / specialty

- `rights_class` / purpose bounds
- `evidence_refs` / provenance hooks
- `created_at` / `last_seen_logical` (logical ≠ live heartbeat claim)

**Discovery:** capability- and purpose-bound directory — discoverable ≠ authorized.  
**Task forces:** ephemeral groupings under §10 — civilization hosts them; does not grant permanent power.

### 2. XACP — XIV Agent Communication Protocol

**XACPV100** — auditable agent↔agent / agent↔system exchange protocol.

**Lifecycle:** `discover → propose → negotiate → commit → execute → report → archive`

| Stage | Meaning | Ban |
|-------|---------|-----|
| discover | find peers / services under rights | discover ≠ authorize |
| propose | offer plan / message | propose ≠ commit |
| negotiate | bounded back-and-forth | negotiate ≠ silent money/contract |
| commit | recorded agreement under auth | commit ≠ Guardian override |
| execute | run within lease + ceiling | execute ≠ unbounded |
| report | outcome + evidence labels | report ≠ rewrite history |
| archive | immutable exchange record | archive ≠ delete audit |

Every exchange carries: sender, recipient, purpose, rights class, evidence refs, causality/confidence label, authority ceiling, Universe scope, audit id. **XACP message ≠ authority grant.** All consequential stages are auditable.

- **Consequential auth** required for approvals that move money, contracts, production, authority, or cross-Universe state
