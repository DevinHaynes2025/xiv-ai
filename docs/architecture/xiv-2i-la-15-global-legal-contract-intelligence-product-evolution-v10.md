## Critical architecture rule (permanent — must remain explicit)

### Correction A — Newly generated stories are DATA not AUTHORITY

Agents may continuously **propose / research / challenge / prioritize / test / split / merge / refine** user stories, but a **newly generated story is DATA not AUTHORITY**.

A story candidate **cannot by itself**:

| Forbidden self-effect | Why |
|-----------------------|-----|
| Deploy / promote release rings | Deployment classification + human/policy gates |
| Increase agent authority / seniority→power | Seniority ≠ authority |
| Weaken security controls | Security-by-design gate |
| Spend without auth | Cost brain + spend auth (LA-16 depth) |
| Access new data classes | Data Access Gateway + RLS |
| Disable Guardian | Guardian immutable from stories |
| Weaken RLS | Schema/RLS changes are gated |
| Change ownership | Ownership is Founder/policy controlled |
| Activate L4 | **L4 DISABLED** |
| Move money | Payments reserved LA-16; never story-auto |
| Sign contracts | Humans + policy sign; AI drafts only |
| Create unrestricted agents | Apprenticeship + Role Generator gates |

**CONTINUOUS LEARNING ≠ UNCONTROLLED SELF-MODIFICATION.**  
When release-critical scope must stabilize, **freeze** it. New ideas remain in **IDEA_POOL** (or equivalent holding states) until promoted through evidence + WIP + Founder/policy gates.

### Correction B — AI legal team ≠ licensed attorneys

`LegalIntelligenceBrain` and AI legal-team agents assist with research, drafting, classification, obligation tracking, and contradiction detection. They are **not** licensed attorneys, not court authority, and not a substitute for human counsel where required. Outputs are labeled advisory / draft / UNKNOWN as appropriate.

### Correction C — LegalDataGateway honesty

**POTENTIAL ≠ CONNECTED.** No fake proprietary legal-database access, no fabricated Westlaw/Lexis/PACER/etc. LIVE claims, no scraped credentials. Connector states must be honest (`NOT_CONFIGURED` / `CONFIGURED` / `VERIFIED` / `FAILED` / `REVOKED`).

### Correction D — Feedback ≠ automatic roadmap

`FeedbackBrain` ingests user/founder/ops feedback as evidence. Feedback **never** auto-writes the roadmap or auto-promotes IDEA_POOL → BACKLOG → DEPLOY without gates.

**Freeze rule:** When release-critical scope is frozen, transitions **out of** `IDEA_POOL` for that scope require Founder/policy override. In-pool refinement may continue.
