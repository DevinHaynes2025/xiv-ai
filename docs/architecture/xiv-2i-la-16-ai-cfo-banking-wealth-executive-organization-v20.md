A UI disclosure such as **“not financial advice”** (or similar fine print) **alone does not** determine whether an activity is regulated.

| Activity class (examples) | Required before enablement |
|---------------------------|----------------------------|
| Personalized investment recommendations | Legal/Compliance Policy + Jurisdiction + Authorized Provider + required controls |

| Brokerage / securities | Same |
| Deposit-taking | Same |
| Lending / credit decisioning | Same |
