## 3. ONE XIV = logical control plane

- partitioned databases

- object stores (media, docs, CAD, scans)

## 4. Universe ≠ physical DB

A **Universe** is a governance / isolation / policy boundary (compose LA-13 / tenant model). It is **not** a physical database, not a shard label alone, and not proof that data colocates.

## 5. Event nervous system

| Object | Contract |
|--------|----------|
| `ProductEvent` | Append-only; typed; tenant/Universe/purpose scoped |
| `InformationEvent` | Same immutability; classification required |
| Nervous system | Ingest → validate → ledger → fan-out → twin projection → audit |
| Replay | Allowed for rebuild; must not invent missing history |
| Dropped event | Must surface UNKNOWN / gap — never fake continuity |

## 6. Bitemporal + immutability

Every authoritative product/information fact carries:

- **valid time** (when true in the world)
- **transaction time** (when XIV learned / recorded it)

Corrections create new versions. Silent UPDATE of history is forbidden for authoritative ledgers.

## 7. Partitioning

Partition keys (document): tenant, Universe, region, product family, time window, storage class, sensitivity. Cross-partition joins are explicit, costed, and permissioned — never ambient.

## 8. Multi-storage fabric

| Search | Discovery | hit ≠ entitlement |

## 10. Product Passport honesty (compose LA-21)

**Product Passport ≠ authenticity.** Passport is a governed record surface. Authenticity requires evidence classes, issuer trust, and verification workflows — UNKNOWN allowed.

## 11. Custody ≠ ownership

Custody chain events record who held / moved / stored a product. Ownership transfer requires legal/commercial rails (compose LA-32) — custody events alone never grant title.

## 12. Latest ≠ live

UI “latest” is a projection with **freshness**, **source**, **confidence**, and **UNKNOWN gaps**. Stale latest must not be labeled LIVE.

## 13. Product location ≠ person location

Location graphs track products / lots / containers / warehouses. Binding to a person requires explicit lawful basis, purpose, and flags; default is **no person tracking**.

## 14. Consumer journey ≠ surveillance

Optional consumer product-journey features (warranty, recall, care) are **purpose-limited**. **`CONSUMER_SURVEILLANCE_ENABLED=FALSE`**. No ambient person graph from product scans.
