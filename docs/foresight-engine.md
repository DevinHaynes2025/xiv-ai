Stances: `observed` · `inferred` · `projected` · `hypothesized` · `recommended`.

Projections are not facts. Hypotheses stay hypothesized. Scenario output includes assumptions, known data, missing data, direction, confidence, dependencies, and unsupported claims.

Phase 2G-B continuous intelligence uses the same stances. Predictions are not converted into facts. See [continuous-intelligence.md](./continuous-intelligence.md) and [realtime-business-intelligence.md](./realtime-business-intelligence.md).
